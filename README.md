# 產品設計的流程｜課堂互動網站（第 1、2 節）

九年級生活科技・翰林九上第二章。老師用手機換頁，投影顯示全班結果，學生用 Chromebook 跟著作答。

## 三個網址

| 誰 | 網址 | 說明 |
|---|---|---|
| 學生 | `index.html?c=課堂代碼` | 投影第一頁有 QR code，學生掃了只要輸入座號 |
| 老師手機 | `teacher.html` | 用老師 PIN 登入，開課、換頁、開始／結束作答、公布 |
| 投影 | `teacher.html?s=課堂編號&mode=screen` | 在教室電腦打開老師網址，登入後到「資料」分頁按「在這台開投影畫面」 |

## 檔案

- `js/content.js`：第 1、2 節的題目、選項、卡片（公開內容）
- 答案、老師提問、2-8 備用回答：放在資料庫（`lesson_private`），只有老師登入後看得到，不在這個網站的檔案裡
- `img/`：原創迷因圖

## 換掉範例內容

1-7 的應援棒計畫、2-9 的三色牌句子標了「範例」。換成自己用 Gemini 問到的內容時：
- 題目文字改 `js/content.js`
- 答案、老師提問改資料庫的 `lesson_private`

## 資料

所有作答存在 Supabase（classroom-foundry-test 專案），資料表都是 `lesson_` 開頭，不會動到班級經營工具的資料。學生網頁只能透過資料庫函式讀寫，不能直接讀資料表；登入只用座號，不收集姓名。
