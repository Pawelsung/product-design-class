## 資料

所有作答存在 Supabase（classroom-foundry-test 專案），資料表都是 `lesson_` 開頭，不會動到班級經營工具的資料。學生網頁只能透過資料庫函式讀寫，不能直接讀資料表；登入只用座號，不收集姓名。


## 班級名單、缺席與分組

老師登入後從「我的班級」選班級，或建立新班級。使用最大座號與座號格設定實際名單（例如 1～30 號中沒有 4、6 號，共 28 人），也能貼上 Excel 的純座號欄。名單與完整分組儲存在 `lesson_class_profiles`，只允許經老師 token 驗證的 RPC 讀寫。

開課前勾選今天缺席的學生，系統只將出席者放入該堂課。班級原始名單不變，下次開課不會沿用今天的缺席。自動分組支援指定組數或每組人數上限，再以拖曳或「點座號→點目標組」調整。班級設定儲存固定分組；控制台「分組」修改當堂分組。

舊課堂依原班級代號匯入「我的班級」，原有列印 QR Code 仍有效。班級名稱可修改，固定代號不變。

## 班級 QR Code 與 PDF

「我的班級」每張班級卡都有「班級 QR Code／桌卡 PDF」；班級設定也能「儲存並產生 QR 桌卡 PDF」，不必手打網址。控制台的「分組」與「資料」也有同一個入口。

PDF 在瀏覽器本機產生：A4 直式、每頁 2×3 張、有組別標籤與裁切虛線；超過六組自動增加頁數，每組可選 1～4 份。QR Code 含四格留白並連到固定班級網址，組別標籤只供擺放參考，學生仍以自己的座號取得正確組別。可下載真正的 `.pdf`，或直接開列印視窗。舊 `qr.html` 列印網址仍可使用。

`js/vendor/` 固定版本：pdf-lib 1.17.1、qrcode-generator 1.4.4；中文文字以高解析度畫布嵌入 PDF，不需連到額外產檔服務。
